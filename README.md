# STOPBLOCK VPN — веб-версия

Веб-сайт с функционалом Telegram Mini App STOPBLOCK VPN: те же экраны и
взаимодействия (меню, тарифы, пробный период, выдача VPN-ссылки с QR,
установка, инструменты, база знаний, рефералы, мини-игры, отзывы, админка),
но без Telegram и без сервера — данные живут в браузере.

## Особенности

- **Демо-бэкенд** (`src/api.ts`): полная замена сетевого API — 30+ функций с
  теми же сигнатурами, данные в `localStorage`, искусственная задержка для
  живых скелетонов загрузки.
- **Тема**: тёмная/светлая с переключателем в шапке; выбор сохраняется,
  первый запуск — по системной настройке.
- **Плавные анимации**: сплэш с щитом, каскадное появление блоков при
  переходах, живой аврора-фон, hover-эффекты на десктопе, тосты вместо
  `alert`. Всё уважает `prefers-reduced-motion`.
- **Маршруты в адресе** (#/plan/1, #/game …): работает кнопка «назад»
  браузера, экраны можно открывать по ссылке.
- **Страницы документов**: `privacy.html`, `terms.html` (статика из `public/`).

## Команды

```bash
npm install        # зависимости
npm run dev        # разработка: http://127.0.0.1:5173/stopblock-site/
npm run build      # прод-сборка в dist/ (с проверкой типов)
npm run preview    # посмотреть сборку: http://127.0.0.1:4173/stopblock-site/
```

## Демо-данные

- Всё состояние — в `localStorage` ключом `stopblock.site.store.v1`.
- **Сброс**: откройте сайт с `?reset=1` — данные обнулятся и страница
  перезагрузится.
- Бонус за приглашение: откройте ссылку вида `…?ref=SB111` (первый раз) —
  +5 дней к подписке.
- Промокоды: `VPN50` (−50%), `VPN20` (−20%), `STOP10` (−10%).
- Оплата имитируется: кнопка «Подтвердить оплату (DEV)».
- «Мой IP» — реальный запрос к api.ipify.org (при недоступности — демо-адрес).
- Викторина и колесо: кулдаун 1 час (в боевом сервисе — сутки).

## Публикация на GitHub Pages

Сборка рассчитана на путь `/stopblock-site/`. Если репозиторий называется
иначе — укажите базовый путь при сборке:

```powershell
$env:VITE_BASE = "/my-repo/"; npm run build
```

## Отличия от мини-аппа

| Было (Mini App)                | Стало (сайт)                              |
| ------------------------------ | ----------------------------------------- |
| Тема из Telegram               | Свой переключатель (сохраняется)          |
| API бота + HMAC initData       | Демо-бэкенд в localStorage                |
| Кнопка Telegram «закрыть»      | Заглушка (экран закрывается сам)          |
| `alert` Telegram               | Плавные тосты                             |
| Нет адресов экранов           | Хэш-маршрутизация (#/buy, #/game …)       |
| —                              | Шапка сайта, подвал, документы-страницы   |

Экраны, компоненты, стили и тексты — из вашего мини-аппа (`../miniapp`),
поэтому дизайн и поведение совпадают.
